# Agent instructions

- Keep changes focused. Use existing templates and `_sass/site.scss`.
- Preserve article URLs, authored content, asset credits, and interactive tools.
  Categories and filenames affect URLs; content views should remain automatic.
- Keep documentation technical and examples generic. Do not record personal
  background, private input, preferences, or conversation history.
- Keep documentation to README.md and this file unless more is requested.
  Avoid speculative helpers, custom checkers, and generated design artifacts.
- Keep unrelated local changes out of commits. For source/configuration changes,
  run `bundle exec jekyll build` once; expand validation only for a concrete concern.
