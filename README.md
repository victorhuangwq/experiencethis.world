# Experience This

Built with Jekyll and published through GitHub Pages. Writing, projects, and
travel articles are organized automatically from Markdown.

## Documentation

- [Publishing guide](docs/publishing.md): write articles, feature them, and list projects.
- [Development guide](docs/README.md): run, build, and check the website.
- [Design reference](docs/DESIGN.md): the implemented visual system and tokens.
- [Product context](docs/PRODUCT.md): the site's purpose and content constraints.
- [Coding-agent instructions](AGENTS.md): guidance for automated changes.

## Source

| Location | Contents |
| --- | --- |
| `_posts/` | Articles; edit once and let section views update. |
| `_projects/` | Project records for work without a full article. |
| [about.md](about.md) | The About page. |
| `_layouts/`, `_includes/`, `_sass/` | Templates and styles. |
| `_dev/` | Build and validation scripts. |
| `docs/` | Repository documentation, excluded from the public site. |
| `_archive/` | Writing kept in Git without publishing. |

Project-specific readmes stay beside their project code. See [LICENSE.md](LICENSE.md)
for the repository license.
